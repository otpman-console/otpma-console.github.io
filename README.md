# otpman-app
#🀄️[作品名] 麻雀×クエスト　レトロなドット絵RPG

##サービス概要
スマホ向けのアプリで、麻雀牌の何を切るかの問題において、期待値が高いものを選択して敵キャラとたたかうアプリ。

##ストーリー
ある日麻雀をしていた主人公は、上がると死んでしまうと言われている伝説の役、九蓮宝燈を上がる。
深夜2時、牌の擦れ合う音だけが響く静まり返った雀荘。

東四局、主人公の配牌は奇妙な偏りを見せていた。
萬子の「一」が3枚、「九」が2枚、そして間を埋める中張牌がパラパラと。

（……染まってるな）

最初はただの清一色（チンイツ）狙いだった。しかし、ツモる手が、恐ろしいほどに噛み合う。
「五萬」を引き、「三萬」を引き、気づけば場に一枚も萬子を捨てないまま、手牌は恐ろしい形へと変貌を遂げていた。

【一 一 一 二 三 四 五 六 七 八 九 九】

手元に残ったのは、完璧な九蓮宝燈のイーシャンテン（あと1枚でテンパイ）。
ゴクリ、と喉が鳴る。

麻雀界において「上がれば死ぬ」とまで言われる、都市伝説級の役満。生涯で一度拝めるかどうかという奇跡が、今、自分の手の中で形を成そうとしていた。

心臓の鼓動がうるさい。他家に気づかれないよう、呼吸を整えてツモに手を伸ばす。
指先が触れた牌を、そっと手元に引き寄せた。腹を親指で撫でる。
——横一文字の溝。

引き当てたのは、3枚目となる「九萬」。

これでテンパイ。しかも、ただのテンパイではない。
「一」が3枚、「二〜八」が各1枚、「九」が3枚。
萬子の「一」から「九」まで、何を上がっても役満となる、純正・九蓮宝燈（九面待ち）。

主人公の視界が、一瞬、ぐにゃりと歪んだような気がした。場に流れる空気が凍りつく。
他家はまだ、主人公がただの派手な染め手に向かっているとしか思っていない。

運命の次巡。
上家が、ため息混じりに安全牌らしき牌を河に置いた。

「——五萬」

その瞬間、主人公の口が、自分でも驚くほど静かに動いていた。

「ロン」

パタパタと、美しく、そして不気味なほどに整った14枚の萬子が卓上に倒される。

「……九蓮宝燈。役満です」

対局相手たちの顔から血の気が引いていくのが分かった。誰も声が出ない。
静寂の中、主人公は自分の手がかすかに震えていることに気づいた。美しい萬子の赤と緑が、まるで生き物のように網膜に焼き付いている。

「上がれば死ぬ」

脳裏をよぎったその言葉と同時に、雀荘の蛍光灯がパチパチと音を立てて激しく瞬きを始めた。
